# Dominoes — site vitrine

Site statique prêt pour GitHub et Cloudflare Pages.

## Déploiement Cloudflare Pages
1. Publier ces fichiers à la racine d'un dépôt GitHub.
2. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git.
3. Choisir le dépôt GitHub.
4. Framework preset: None. Build command: laisser vide. Build output directory: `/` (racine du dépôt).
5. Déployer.

La page de confidentialité sera accessible à `https://VOTRE-PROJET.pages.dev/privacy.html`.

**Important** : revoir et personnaliser privacy.html avant d'utiliser son URL dans Google Play ou App Store Connect. Le texte fourni est un modèle, pas une validation juridique ni une description vérifiée du comportement de l'application.
